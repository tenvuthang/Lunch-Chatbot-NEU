1.1. Tham số lấy từ model thật (src/classifier.py: NeedClassifier -> build_model('nb'))
   TfidfVectorizer: ngram_range=(1, 2), sublinear_tf=True, min_df=1, lowercase=True, use_idf=True, smooth_idf=True, norm='l2'
                    token_pattern = r"(?u)\b\w\w+\b" (chỉ giữ token ≥ 2 ký tự; '_' thuộc \w nên 'bình_dân' là 1 token)
   MultinomialNB:   alpha = 0.5, fit_prior = True
   Công thức:
     tf'(t,d)   = 1 + ln(tf(t,d))                    (sublinear_tf=True, chỉ áp dụng khi tf > 0)
     idf(t)     = ln((1 + n) / (1 + df(t))) + 1       (smooth_idf=True), n = số văn bản huấn luyện
     w(t,d)     = tf'(t,d) × idf(t)
     x(d)       = w(·,d) / ||w(·,d)||₂                (chuẩn hóa L2)
     P(C)       = n_C / n
     N(C,t)     = Σ_{d ∈ C} x_t(d);   N(C) = Σ_t N(C,t)
     P(t|C)     = (N(C,t) + alpha) / (N(C) + alpha·|V|)
     log P(C|x) ∝ ln P(C) + Σ_t x_t · ln P(t|C);  P(C|x) = softmax của các giá trị này
